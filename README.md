# Siaivo Dorama

[![Tests](https://github.com/Lamp1ch-chmuk/dorami-Siaivo/actions/workflows/ci.yml/badge.svg)](https://github.com/Lamp1ch-chmuk/dorami-Siaivo/actions/workflows/ci.yml)

Плагін для актуальної Siaivo / Lampa 3.x, який додає **одну окрему категорію «Дорами» в ліву навігацію**.

**Короткий URL для підключення:**
[https://da.gd/siaivod](https://da.gd/siaivod)

Плагін **нічого не додає на головну сторінку**.

## Версія

`0.5.0`

Аудит API публічної Siaivo `3.3.4.29` (`app_digital 33429`) — 2026-10-02.
Живі дані, результати й межі перевірки: [аудит каталогу 0.5.0](docs/CATALOG-AUDIT.md).
Попередня перевірка API: [аудит 0.4.1](docs/AUDIT.md).

## Архітектура

- один пункт `Дорами` у штатному лівому меню через `Lampa.Menu.addButton`;
- відкриття штатного route `category` через `Lampa.Router.call`;
- namespaced custom source `plugin_siaivo_dorama` відповідає лише за рядки категорії та `category_full` пагінацію;
- самі картки завжди мають `source: 'tmdb'`, тому details / актори / сезони обробляє штатний TMDB source;
- каталог вантажиться через штатні `Lampa.Reguest` і `Lampa.TMDB.api/key`, зі збереженням налаштованого проксі;
- рядки та `Ще` використовують спільний кеш; у сітці дві TMDB-сторінки на одну сторінку перегляду;
- українські/локалізовані назви зберігаються; відсутній переклад доповнюється англійською назвою з однієї додаткової сторінки;
- на старих збірках без цих API використовується сумісний шлях `tmdb.get` / `Api.list` із фільтрами самого застосунку;
- рядки вантажаться ліниво через `Lampa.Api.partNext` по 4;
- жодних `ContentRows` на main, monkey-patch `Activity.push`, власного TMDB API key або записів у глобальний `Storage`.

## Як визначається «дорама»

TMDB не має окремого типу `dorama`. Базова вибірка тому не прирівнює дораму до жанру Drama (`18`). Вона використовує:

- країну походження;
- оригінальну мову;
- TV type `2|4` (Miniseries OR Scripted);
- `without_genres=16,99,10763,10764,10767` для виключення анімації, документалістики, новин, реаліті та ток-шоу.

Жанри додаються лише тематичним рядкам: Comedy (`35`), Mystery (`9648`), Sci‑Fi & Fantasy (`10765`).

Це автоматична евристика, а не редакційна класифікація. Для тропів на кшталт school romance, revenge, BL, xianxia/wuxia, time travel тощо краще пізніше додати curated-підбірки.

## Дати та часовий пояс

У `0.4.0` виправлено важливий edge case: date-sensitive корейські рядки більше не використовують календарний день пристрою.

Плагін сам обчислює поточний день Кореї як UTC+9 без `Intl`, щоб працювати на старих TV WebView, і передає TMDB `timezone=Asia/Seoul` для `air_date.gte/lte`.

Через це, наприклад, ввечері в Європі, коли в Сеулі вже наступний день, «Нові серії» не відстають на добу.

Route рядка має вигляд:

`siaivo-dorama:YYYY-MM-DD:<section_id>`

Anchor date фіксується при вході у категорію, тому пагінація не перебудує запит, якщо дата зміниться, поки користувач знаходиться всередині розділу.

## Свіжість і кеш

Рядки та «Ще» використовують однаковий нативний кеш `Lampa.Reguest`:

| Добірка | Час кешу |
| --- | --- |
| Нові серії, онгоїнги | 2 години |
| Нові дорами | 6 годин |
| Популярні корейські | 12 годин |
| Жанри, канали, інші країни | 24 години |
| Високий рейтинг | 72 години |

При повторному відкритті добірки прострочені сторінки завантажуються заново.
Відкрита сітка сама не перебудовується: це зберігає фокус і пагінацію. Фонових
таймерів, опитування всіх 14 добірок або запитів перекладу для кожної картки немає.
Якщо у Siaivo вимкнено кешування запитів, використовується її налаштування.
За мережевої помилки нативний клієнт може повернути раніше кешовану відповідь.

## Чому онгоїнгів і новинок менше

Популярне охоплює весь каталог. Онгоїнги — вже розпочаті серіали зі статусом
Returning Series / In Production та датами епізодів у вікні ±21 день.
«Нові серії» охоплюють останні 14 днів; «Нові дорами» — прем'єри за 180 днів,
а не нові сезони старих серіалів.

У 0.5.0 окремий каталог дорам перестав успадковувати загальний поріг голосів,
відсів неперекладених назв і виключення Soap із Discover-фільтра Siaivo.
Ці фільтри прибирали більшість новинок навіть у «Ще». Класифікація за країною,
мовою, типом та жанрами лишається; глобальні фільтри інших розділів не змінено.

Якщо TMDB не має й англійського перекладу, зберігається оригінальна назва.
Неточні жанри/типи та відсутні дати в TMDB можуть впливати на склад добірок.
Наявність картки не гарантує наявності озвучення чи відео у підключеному джерелі.

## Меню

Menu action та source namespaced:

- `data-action="plugin_siaivo_dorama"`
- `source="plugin_siaivo_dorama"`

Назва пункту навмисно завжди `Дорами`, незалежно від мови UI. Поточний редактор Siaivo зберігає `menu_sort` / `menu_hide` за **видимим текстом**, тому зміна `Дорами ↔ Дорамы` скидала б збережену позицію/видимість.

Siaivo сама підхоплює динамічно доданий `.selector` у штатний редактор меню, тому окремий settings-toggle плагіну не потрібний.

Залишається обмеження ядра: якщо інший плагін створить пункт із точно такою самою видимою назвою `Дорами`, редактор Siaivo може змішати їх при sort/hide.

## Безпека та сумісність коду

- ES5-style авторський код: без `let/const`, arrow functions, `async`, `Promise`, `fetch`;
- без залежності від `Intl` для KST-дати;
- без `console.log.apply`, що іноді проблемне на старих TV WebView;
- відповіді TMDB не мутуються: root object, `results` і картки копіюються перед додаванням metadata;
- карткам примусово ставиться `source: 'tmdb'`;
- boot retry має верхню межу;
- source/menu IDs namespaced;
- чужий custom source з тим самим ID не перезаписується.

## Встановлення

Коротка адреса для набору з пульта:

```text
https://da.gd/siaivod
```

Це HTTPS-редирект прямо на JS-файл плагіна. Адресу перевірено: вона повертає
`application/javascript`, а вміст збігається з `d.js` у репозиторії.

Пряма адреса без сервісу скорочення (для **публічного** репозиторію):

```text
https://cdn.jsdelivr.net/gh/Lamp1ch-chmuk/dorami-Siaivo@main/d.js
```

`d.js` — повна копія `siaivo-dorama.js`, а не завантажувач чи сторінка редиректу.
Цей URL слідує гілці `main`; оновлення CDN може з'являтися із затримкою.

Для **публічного** репозиторію можна використати URL версії через jsDelivr:

```text
https://cdn.jsdelivr.net/gh/Lamp1ch-chmuk/dorami-Siaivo@v0.5.0/siaivo-dorama.js
```

У Siaivo: **Налаштування → Розширення → Додати плагін**, встав URL,
потім повністю перезапусти застосунок. У лівому меню з'явиться **Дорами**.
Пункт можна приховати або перемістити штатним редактором меню Siaivo.

CDN потребує публічного GitHub-репозиторію й може оновлювати кеш із затримкою.
Альтернатива — розмістити `siaivo-dorama.js` на власному HTTPS-хостингу чи
GitHub Pages. Не використовуй GitHub blob-посилання як URL плагіна.

Після оновлення файлу краще **повністю перезапустити Siaivo**. Hot reload не є коректним способом перевірки, бо попередній JS уже міг зареєструвати listener/source/menu item у поточному `window`.

## Локальна перевірка

Для повної перевірки потрібен Node.js 22+:

```bash
npm ci --ignore-scripts
npm test
```

Базовий тест усіх 14 рядків можна запустити без встановлення devDependencies:
`node test.js`. У самого плагіна немає npm-залежностей — встановлюється один JS-файл.

`npm test` також виконує 26 перевірок життєвого циклу, конфліктів, мережевих
помилок, fallback, асинхронного порядку, дат, перекладів, пагінації, пошкоджених даних та ES5 через Acorn.
GitHub Actions повторює перевірки на Node.js 22/24 і в різних часових поясах.

Реальна Siaivo UI + підставлені TMDB-відповіді перевіряються командою
`npm run test:browser`: [підготовка та опис](docs/AUDIT.md).
Правила розробки: [CONTRIBUTING.md](CONTRIBUTING.md).

## Що ще не перевіряє mock

Mock не може довести реальну поведінку focus/remote/render на конкретному Tizen/webOS/Android TV WebView. Ризик зменшений тим, що плагін не створює власний Card/Line/Main UI — він використовує штатний `category` Lampa.

Також `CN + zh` означає передусім материковий Китай. Тайвань (`TW`) і Гонконг (`HK`) краще додати окремо в наступній контентній ревізії.
