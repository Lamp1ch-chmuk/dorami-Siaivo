# Siaivo Dorama

[![Tests](https://github.com/Lamp1ch-chmuk/dorami-Siaivo/actions/workflows/ci.yml/badge.svg)](https://github.com/Lamp1ch-chmuk/dorami-Siaivo/actions/workflows/ci.yml)

Плагін для актуальної Siaivo / Lampa 3.x, який додає **одну окрему категорію «Дорами» в ліву навігацію**.

**Постійний короткий URL для підключення й усіх наступних оновлень:**
[https://da.gd/siaivod](https://da.gd/siaivod)

Плагін **нічого не додає на головну сторінку**.

Адреса однакова для всіх версій. Якщо вже встановлено `https://da.gd/siaivod`,
змінювати її не потрібно. Якщо встановлено `siaivod5` або URL із тегом версії,
заміни його на постійний URL один раз і повністю перезапусти Siaivo.
Не залишай одночасно старий і новий запис цього плагіна.

Якщо у браузері за цією адресою ще видно **0.4.1**, примусово перезавантаж
вкладку через **Ctrl+Shift+R / Ctrl+F5**. jsDelivr дозволяє кешувати файл на
пристрої 7 днів; очищення CDN не видаляє цю локальну копію.
Свіжий `d.js` починається з `Siaivo Dorama permanent loader v1`.
Номер 0.7.0 належить повному `siaivo-dorama.js`, який він завантажує окремо.

## Архітектура

- `d.js` — постійний ES5-завантажувач актуального `siaivo-dorama.js` із гілки `main`;
- один пункт `Дорами` у штатному лівому меню через `Lampa.Menu.addButton`;
- відкриття штатного route `category` через `Lampa.Router.call`;
- namespaced custom source `plugin_siaivo_dorama` відповідає лише за рядки категорії та `category_full` пагінацію;
- самі картки завжди мають `source: 'tmdb'`, тому details / актори / сезони обробляє штатний TMDB source;
- каталог вантажиться через штатні `Lampa.Reguest` і `Lampa.TMDB.api/key`, зі збереженням налаштованого проксі;
- рядки та `Ще` використовують спільний кеш; у сітці дві TMDB-сторінки на одну сторінку перегляду;
- українські/локалізовані назви зберігаються; відсутній переклад доповнюється англійською назвою з однієї додаткової сторінки;
- на старих збірках без цих API використовується сумісний шлях `tmdb.get` / `Api.list` із фільтрами самого застосунку;
- рядки вантажаться ліниво через `Lampa.Api.partNext` по 4;
- жодних `ContentRows` на main, monkey-patch `Activity.push`, власного TMDB API key або записів у глобальний `Storage`.

3. 🇯🇵 Популярні японські дорами

## Як визначається «дорама»

TMDB не має окремого типу `dorama`. Добірки використовують країну походження,
оригінальну мову (для окремих країн), тип Miniseries OR Scripted та один із
жанрів ігрового серіалу: драма, комедія, кримінал, детектив, пригоди, фантастика,
сімейний, Soap або War & Politics. Це дозволяє зберегти комедії й щоденні дорами.

Виключаються анімація, дитячі передачі, документалістика, новини, реаліті й
ток-шоу, а також TMDB keywords `anime`, `tokusatsu`, `variety show`,
`sports entertainment` та китайського лялькового театру. Підтверджені помилково
класифіковані передачі додатково виключені за TMDB ID. Картки додатково проходять
локальний відсів: жанри, підтверджені не-дорами та збіги з уже завантаженою картою аніме
Сяйва. Для цього не потрібні окремі запити деталей кожного серіалу.
Японська мова сама по собі не вважається ознакою аніме.

### Як визначається популярність

Усі добірки запитують **`sort_by=popularity.desc`**. TMDB розраховує індекс
за активністю користувачів: щоденними переглядами сторінок, голосами,
додаванням у вибране та список перегляду. Він також враховує загальні голоси,
попереднє значення індексу й дату останнього/наступного епізоду.

**Обмежень року чи діапазону дат немає.** Дорами 2000-х, 2015–2020,
2026 року та іншого віку можуть бути поруч, якщо ними цікавляться користувачі.
Немає мінімальної оцінки чи кількості голосів: активний інтерес до невеликої
дорами може виникнути до появи багатьох оцінок. Невідома дата виходу теж
не приховує картку. Плагін зберігає порядок TMDB, не пересортовує за роком.

Це індекс інтересу **користувачів TMDB**, а не статистика запусків відео
у Сяйві чи лише українських глядачів. TMDB описує popularity як накопичений
показник зі щоденними чинниками; точну формулу й сирі лічильники не публікує.
Короткі day/week `trending` є іншою метрикою, але загальний глобальний список
не забезпечує повноцінні регіональні каталоги та тематичний ЛГБТ-фільтр.
Для цих добірок використовується регіональний Discover за popularity.
[Офіційний опис](https://developer.themoviedb.org/docs/popularity-and-trending).

### Одна спільна ЛГБТ-добірка

«🏳️‍🌈 ЛГБТ-дорами» об'єднує Південну Корею, Японію, Таїланд, Китай, Тайвань,
Гонконг, Філіппіни, В'єтнам і Сінгапур в **одному рядку та одній сітці «Ще»**.
Використовуються тематичні TMDB keywords LGBT, BL, GL, gay/lesbian/LGBT/transgender
romance. Їхні ID перевірено через API; добірка не визначається випадковими словами
в назві чи наявністю романтики взагалі.

Сортування — за тим самим індексом популярності, без обмежень дат,
кількості голосів або оцінки.
Окремого мовного фільтра немає: корейська, японська, тайська та інші мови
можуть співіснувати. Країни не мають штучних квот; склад залежить від каталогу
та популярності TMDB. Загальні правила відсіву аніме й шоу застосовуються й тут.

Класифікація спирається на заповнення TMDB. Помилкові або відсутні жанри,
keywords можуть впливати на результати. Докладні правила й перевірки:
[аудит популярності](docs/POPULARITY-AUDIT.md).

## Маршрути

Для сумісності збережено датований формат:

`siaivo-dorama:YYYY-MM-DD:<section_id>`

Дата в маршруті фіксує відвідування категорії; вона **не є фільтром дати виходу**.
День обчислюється в UTC+9 незалежно від часового поясу телевізора, без `Intl`.
Рядки та «Ще» використовують однакові запити й правила фільтрації.

## Свіжість і кеш

Усі шість добірок і «Ще» використовують спільний нативний кеш `Lampa.Reguest`
на **6 годин**. Повторне відкриття після спливання TTL отримує актуальний порядок.
Коли рядок уже завантажено, «Ще» повторно використовує його першу сторінку.

Відкрита сітка сама не перебудовується: це зберігає фокус і пагінацію.
Фонових таймерів, опитування всіх добірок або запитів для кожної картки немає.
Якщо у Siaivo вимкнено кешування запитів, використовується її налаштування.
За мережевої помилки нативний клієнт може повернути раніше кешовану відповідь.

Локалізована назва зберігається. За відсутнього перекладу використовується одна
англійська сторінка зі зіставленням за ID, а за відсутності й англійської —
оригінальна назва. Наявність картки не гарантує відео чи озвучення у джерелі.

## Меню

Menu action та source namespaced:

- `data-action="plugin_siaivo_dorama"`
- `source="plugin_siaivo_dorama"`

Назва пункту навмисно завжди `Дорами`, незалежно від мови UI. Поточний редактор Siaivo зберігає `menu_sort` / `menu_hide` за **видимим текстом**, тому зміна `Дорами ↔ Дорамы` скидала б збережену позицію/видимість.

Siaivo сама підхоплює динамічно доданий `.selector` у штатний редактор меню, тому окремий settings-toggle плагіну не потрібний.

Залишається обмеження ядра: якщо інший плагін створить пункт із точно такою самою видимою назвою `Дорами`, редактор Siaivo може змішати їх при sort/hide.

## Безпека та сумісність коду

- ES5-style авторський код: без `let/const`, arrow functions, `async`, `Promise`, `fetch`;
- без залежності від `Intl` для KST-дати;
- без `console.log.apply`, що іноді проблемне на старих TV WebView;
- відповіді TMDB не мутуються: root object, `results` і картки копіюються перед додаванням metadata;
- карткам примусово ставиться `source: 'tmdb'`;
- boot retry має верхню межу;
- source/menu IDs namespaced;
- чужий custom source з тим самим ID не перезаписується.

## Встановлення й оновлення

Введи у **Налаштування → Розширення → Додати плагін**:

```text
https://da.gd/siaivod
```

Потім повністю перезапусти Siaivo. У лівому меню з'явиться **Дорами**.
Пункт можна приховати або перемістити штатним редактором меню.

**Після наступних релізів URL міняти не потрібно:** повний перезапуск перевіряє
актуальний код. Відкрита Siaivo сама код не замінює, щоб зберігати фокус і стан.
Оновлення списків серіалів окремо використовує 6-годинний TTL.
Під час першого переходу зі старого повного JS на завантажувач може знадобитися
одноразове примусове оновлення браузерного кешу. Звичайний перезапуск цього кешу
не очищає; після завантаження нового `d.js` його кешування не заважає отриманню
нових версій повного плагіна.

Пряма постійна адреса без скорочувача:

```text
https://cdn.jsdelivr.net/gh/Lamp1ch-chmuk/dorami-Siaivo@main/d.js
```

Короткий URL перенаправляє на `d.js`. Це завантажувач, а не копія повного плагіна:
один запит на запуск отримує актуальний код із GitHub Raw із параметром свіжості.
При недоступному оновленні використовується останній збережений код; на першій
установці без кешу є резервний запит через CDN. HTML/помилки не записуються як код.
Збереження виконується лише у приватний ключ завантажувача, без зміни меню й налаштувань.

Після успішних тестів GitHub Actions перевіряє й за потреби очищає CDN для двох
JS-файлів. Не потрібно створювати нове скорочення чи URL з новим тегом релізу.
Старі адреси на фіксовані версії залишаються архівними й автоматично не оновлюються.
Докладніше: [доставка та її межі](docs/DELIVERY.md).

## Локальна перевірка

Для повної перевірки потрібен Node.js 22+:

```bash
npm ci --ignore-scripts
npm test
```

Базовий тест усіх 6 рядків можна запустити без встановлення devDependencies:
`node test.js`. У самого плагіна немає npm-залежностей — підключається одна постійна адреса.

`npm test` також виконує 44 перевірки життєвого циклу, конфліктів, мережевих
помилок, fallback, асинхронного порядку, дат, перекладів, пагінації, пошкоджених даних, відсутності вікових/голосових обмежень, єдиної ЛГБТ-добірки, відсіву аніме, оновлення завантажувача, офлайн-кешу та ES5 через Acorn.
GitHub Actions повторює перевірки на Node.js 22/24 і в різних часових поясах.

Реальна Siaivo UI + підставлені TMDB-відповіді перевіряються командою
`npm run test:browser`: [підготовка та опис](docs/AUDIT.md).
Правила розробки: [CONTRIBUTING.md](CONTRIBUTING.md).

## Що ще не перевіряє mock

Mock не може довести реальну поведінку focus/remote/render на конкретному Tizen/webOS/Android TV WebView. Ризик зменшений тим, що плагін не створює власний Card/Line/Main UI — він використовує штатний `category` Lampa.

`CN + zh` у китайському рядку означає передусім материковий Китай. Тайвань
і Гонконг уже включено у спільну ЛГБТ-добірку.
