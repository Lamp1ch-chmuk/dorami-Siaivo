# Changelog

## 0.7.0 — 2026-10-02

- Залишено лише популярні корейські, китайські, японські, тайські, тайванські
  дорами та одну загальну ЛГБТ-добірку. Жанри, Netflix, tvN, JTBC, високий
  рейтинг, нові серії й онгоїнги повністю видалено.
- Знято всі межі року/дати випуску й пороги оцінки/кількості голосів,
  включно з ЛГБТ. Порядок `popularity.desc` використовує індекс TMDB із
  щоденною активністю користувачів та накопиченим інтересом; дата випуску
  сама по собі не приховує дораму. Невідомі дати також дозволені.
- Усі рядки й «Ще» мають спільний кеш 6 годин. Збережено ліниву чергу,
  2:1 пагінацію, переклади, карту аніме та штатні TV details.
- За результатами живого аудиту додано variety/sports-entertainment/puppetry
  keyword-виключення та п'ять підтверджених не-дорам за ID: TMDB помилково
  класифікує реслінг, естрадні й лялькові передачі як Scripted/Drama.
- Оновлено 44 Node-тести та Chromium smoke для шести рядків, старих/нових
  дорам, ЛГБТ «Ще», відсутності меж дат, спільного TTL й збереження відсіву аніме.
- Поточна метрика, її межі та живі результати: [аудит популярності](docs/POPULARITY-AUDIT.md).
  Постійний URL https://da.gd/siaivod не змінено.

  відкриття та помірним порогом 10 голосів; порядок — поточна популярність.
  Для ЛГБТ достатньо 5 голосів, для високого рейтингу лишилося 100.
  В онгоїнгах і нових серіях порога голосів немає.

  контенту, anime/tokusatsu keywords, локальні перевірки та нативна карта аніме.
  Японські ігрові серіали не відсіюються за мовою.

  до допоміжного перекладу. Нових запитів на кожну картку або таймерів немає.

  ЛГБТ-сітку й відсів аніме, помилково позначеного жанром Drama.

  Постійна адреса https://da.gd/siaivod і завантажувач залишилися тими самими.

## 0.5.0 — 2026-10-02

- Усунено втрату новинок та онгоїнгів через загальні Discover-фільтри Siaivo:
  каталог дорам використовує штатні Reguest/TMDB API зі своїми умовами вибірки.
  Деталі, сезони, картки й проксі лишаються нативними; глобальні API не патчаться.

  перекладу або помилка допоміжного запиту більше не приховує серіал.

- Уточнено жанрові виключення: анімація, документалістика, новини, реаліті, ток-шоу.

  обмеження 500 сирих сторінок TMDB та відсутність запиту за останню непарну сторінку.
  Помилка основної сторінки не видається за успішний неповний результат.
- Додано 10 тестів каталогу. Браузер перевіряє повні рядки, переклади, спільний
  нативний кеш і його реальне спливання; живий TMDB звірено окремо.
- Результати й обмеження: [аудит каталогу](docs/CATALOG-AUDIT.md).

## 0.4.0 — 2026-10-02

Повний повторний аудит від bootstrap до TMDB pagination проти актуальної Siaivo `3.3.4.29` / Lampa 3.x.

### Виправлено

- Назва лівого menu item тепер завжди `Дорами`. Це навмисно: поточна Siaivo зберігає порядок/приховування пунктів за видимим текстом, тому локалізована `Дорами ↔ Дорамы` робила menu state нестабільним.
- Date-sensitive корейські рядки тепер прив'язані до **календарної дати Сеула**, а не локальної дати пристрою.
- Для `air_date.gte/lte` додано `timezone=Asia/Seoul`.
- KST-дата обчислюється як UTC+9 без `Intl`, щоб не погіршувати сумісність зі старими TV WebView.
- `rowCache()` більше не підмінює допустиме numeric `cache_life=0` дефолтним значенням через `||`.
- Карткам після копіювання безумовно ставиться `source: 'tmdb'`, щоб details/person/seasons завжди йшли штатним TMDB source.
- Логування більше не залежить від `console.*.apply`, яке може бути проблемним для host-функцій старих WebView.
- Додано діагностику конфлікту, якщо namespaced menu action уже зайнятий іншим плагіном.
- Посилено нормалізацію `page`, `total_pages`, `total_results`.

### Перевірено й залишено без змін

- `Lampa.Api.partNext` зберігає порядок рядків: актуальний `Progress` записує результат за індексом задачі.
- `clear()` custom source лишається порожнім: глобальний `Lampa.Api.clear()` сам проходить по всіх sources і окремо очищає штатний TMDB/network.
- `Api.list()` навмисно лишився шляхом для `category_full`, бо Siaivo патчить Discover grid і зливає дві TMDB-сторінки на view-page.
- custom source не реалізує `full/person/seasons`: картки `source: 'tmdb'` і штатний Router/Lampa API роблять це самі.
- окремий settings-toggle не додано: поточний Siaivo menu editor через MutationObserver підхоплює динамічно доданий menu selector.

### Документовано

- Плагін успадковує глобальний Discover-filter Siaivo: hard vote floor, readable-title filter, anime exclusion, `Soap (10766)` exclusion та 2:1 page merge. Через це частина нішевих/щоденних дорам може бути прихована політикою самої Siaivo.
- Повний grid використовує нативний `tmdb.list()` cache; короткі горизонтальні рядки мають власні freshness-aware cache life.

### Тести

- усі 14 секцій повинні бути досяжні через lazy batches `4 + 4 + 4 + 2`;
- перевіряється KST boundary: `2026-10-01 16:30 UTC` має дати anchor `2026-10-02`;
- перевіряється `timezone=Asia/Seoul` у date-sensitive queries;
- перевіряється non-mutating TMDB response;
- перевіряється stable dated pagination;
- перевіряється namespaced menu/source routing;
- перевіряється ES5-style і відсутність deprecated/home-injection API.
